# Claude Code 概念解剖

> 从八个方向切开 Claude Code，再用切面透视它的源码架构。
> 基于对 `@anthropic-ai/claude-code` v2.1.88 还原源码的阅读。

---

## 一、定锚

**Claude Code 是什么**：运行在终端里的 AI 编程 Agent——能读写文件、执行命令、调用 API，以多轮对话循环完成软件工程任务。

**不是什么**：
- 不是代码补全插件（它是自主 Agent，能规划、执行、纠错）
- 不是 "Claude 套壳"（有独立的权限系统、状态管理、多 Agent 协调、上下文压缩、记忆持久化）
- 不是程序员替代品（是杠杆——放大意图，但支点和方向由人决定）

---

## 二、五把刀

### 2.1 辩证刀：工具越强，品味越重要

架构的核心张力是**自主性 vs 控制**：

- Agent 循环赋予自主行动能力（读写文件、执行命令、生成子 Agent）
- 权限系统四层叠加（MDM > 全局 > 项目 > 本地）+ Hook 脚本把它拴住

去掉权限层 → 危险的自动化脚本；去掉 Agent 循环 → 退化成聊天机器人。两者的张力定义了产品形态。

更深一层：协调器模式（Coordinator Mode）中主 Agent "只编排不干活"——**自主性的自我限制**。权力越大的 Agent 越不直接执行，和管理学同构。

对人的影响：Claude Code 把"做"的成本降到接近零，迫使人退回到**判断**——该做什么、不该做什么、何时停下。这个位置本质上不可自动化。

### 2.2 形式刀：从天真公式到诚实公式

**天真公式**（看起来优雅，但撒了三个谎）：

```
Agent(s, m) = case API(s, m) of
  | end_turn    -> done
  | tool_use(t) -> Agent(s, m ++ [call, Execute(t)])
```

三个谎言：假装环境不变、消息只增不减、工具执行是纯函数。

**诚实公式**（加入压缩和状态）：

```
Agent(ctx, state, m) = let (state', m') = Compress(state, m)
                       in case API(state', m') of
                         | end_turn    -> (state', m')
                         | tool_use(t) -> let (state'', r) = Execute(t, ctx, state')
                                          in Agent(ctx, state'', m' ++ [t, r])
```

三个参数的变化节奏完全不同：

| 参数 | 对应源码 | 变化频率 |
|------|---------|---------|
| `ctx` | `ToolUseContext` | 整个会话不变（依赖注入容器） |
| `state` | `AppState`（80+ 字段） | 每轮被修改两次（压缩一次、工具执行一次） |
| `m` | `messages: Message[]` | 每轮追加或被压缩收缩 |

关键洞察：

- **`Compress(state, m) -> (state', m')`** — 压缩不是无状态的文本操作，它有记忆（`hasAttemptedReactiveCompact` 防死循环标记）。对应四级管线：Snip → Microcompact → Context Collapse → Autocompact
- **`Execute(t, ctx, state') -> (state'', r)`** — 工具返回的不只是结果 `r`，还有被修改的状态 `state''`。`AgentTool` 会改任务注册表，`TodoWrite` 会改待办列表，`Edit` 会改文件缓存。天真公式假装工具只产出结果不碰世界，这是假的
- **形式上依然是尾递归** — 源码中 `state = {...}; continue` 就是这个递归的命令式翻译。所有状态集中在参数里，可以在任意轮次暂停和恢复

一句话：**Agent 的每一步都在改变自己下一步运行的环境。**

### 2.3 现象刀：意图自行展开

扔掉所有技术术语，回到体验本身：你说了一句话，然后看着屏幕上的文字一行行冒出——它读文件、找依赖、改代码、跑测试、看错误、再改——整个过程你只说了一句话。

**这个体验的本质：你表达了一个意图，然后看着意图自行展开成行动。**

架构揭示了展开的六层套娃：

```
人的意图（自然语言）
  -> QueryEngine 展开为 system prompt + 消息 + 工具集
    -> query() 展开为 API 调用
      -> API 返回展开为 tool_use 指令
        -> 工具执行展开为文件读写 / 命令执行
          -> 子 Agent 展开为独立循环（递归嵌套）
```

每一层都是一次**具体化**：模糊变具体，抽象变可执行。

Skill 系统是这个展开过程的**加速器**——预制的展开路径，把"某类意图如何变成行动"的知识固化。三种来源（内置/磁盘/MCP）= 三种固化时机（编译时/部署时/运行时）。

### 2.4 元反思刀：架构图的隐喻盲区

`0.ARCHITECTURE.md` 用**层次结构**隐喻描述架构：入口点 → 核心循环 → 工具体系 → 服务层。

**这个隐喻挡住了回路**：
- 工具执行结果改变下一轮 system prompt（记忆提取）
- 子 Agent 的 task-notification 注入主 Agent 消息流
- 压缩系统重写历史消息
- MCP 动态连接改变可用工具集

信息不是瀑布式向下流，而是**到处回流**。

**替代隐喻——呼吸的有机体**：

| 器官 | 架构组件 | 功能 |
|------|---------|------|
| 大脑 | Claude 模型 | 决策 |
| 手 | 40+ 工具 | 行动 |
| 眼 | Read/Glob/Grep | 感知 |
| 免疫系统 | 权限四层 + Hook | 防御 |
| 肺 | 压缩管线 | 呼吸（吐旧吸新） |
| 记忆 | SessionMemory | 长期存储 |
| 分裂 | AgentTool + Coordinator | 分身 |

有机体隐喻更好地捕捉了**自稳态**：呼吸维持上下文不爆，免疫阻止危险行动，记忆保持跨对话连续性。

### 2.5 美感刀：消失

最好的工具是透明的。Claude Code 运行在终端里，没有花哨 GUI。当它工作得最好的时候，你忘记了它在那里。

意象：**一面磨到极薄的透镜**——光穿过时几乎无折射，但你看到的世界清晰了一个量级。

## 三、深层结构：展开-折叠的分形

"迭代展开"不只是核心循环的逻辑，它在架构的三个维度重复出现：

```
  时间维度              空间维度              信息维度
  (核心循环)            (多 Agent)           (压缩管线)
                                          
  意图                  主 Agent             完整历史
   |                    /    \               |
   v                   v      v              v
  API调用           子Agent  子Agent       Snip
   |                 |        |             |
   v                 v        v              v
  tool_use        独立循环  独立循环      Microcompact
   |                 |        |             |
   v                 v        v              v
  执行+结果        结果汇回  结果汇回     Autocompact
   |                    \    /               |
   v                     v                   v
  下一轮              汇总继续           压缩后的历史
  (展开)              (展开)             (折叠)
```

- **时间上展开**：每轮循环把意图具体化一步
- **空间上展开**：分裂成子 Agent 并行展开
- **信息上折叠**：把展开过的历史压缩，为下一轮腾出空间

**三者嵌套构成一个能持续运转的系统。呼气是为了下一次吸气。**

## 四、压缩

**公式**：`Claude Code = while(意图未落地) { 感知 → 决策 → 行动 → 反馈 }`

**一句话**：它是一台把自然语言意图迭代展开为代码行动的机器，每一步都在改变自己下一步运行的环境。工具越强，品味越重要。

**骨架**：

```
                    +------------------+
                    |    Human Intent  |
                    +--------+---------+
                             |
                             v
              +--------------+---------------+
              |        QueryEngine           |
              |  (system prompt + context)   |
              +--------------+---------------+
                             |
                   +---------+---------+
                   |                   |
                   v                   v
            +------+------+    +------+------+
            |   query()   |    |  Compress   |
            | Agent Loop  |<-->|  Pipeline   |
            +------+------+    +-------------+
                   |
         +---------+---------+
         |         |         |
         v         v         v
      +--+--+  +--+--+  +--+--+
      |Read |  |Edit |  |Bash |  ...40+ tools
      +-----+  +-----+  +-----+
         |         |         |
         v         v         v
    +----+----+----+----+----+----+
    |       Codebase / World      |
    +-----------------------------+
```
